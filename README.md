# MySport — виды спорта и дисциплины (фрагмент)

Этот репозиторий содержит **только новую часть** проекта «My Sport»
(спортивная коммьюнити-платформа на TanStack Start + Convex): справочник
видов спорта, синхронизированный с официальным Всероссийским реестром видов
спорта (ВРВС), и дисциплины внутри каждого вида спорта.

Основной проект (события, площадки, авторизация, админка, UI и т.д.)
размещён и разрабатывается в Macaly Cloud и сюда не переносился — это
осознанно отдельный фрагмент, который можно слить обратно в основной
проект.

## Структура

- `convex/schema.ts` — фрагмент схемы: таблица `sports` (вид спорта + раздел
  реестра + код + номер + список дисциплин).
- `convex/sports.ts` — CRUD-мутации и запрос списка видов спорта, плюс
  `importRegistry` для первоначальной загрузки реестра.
- `convex/migrations.ts` — одноразовая миграция `syncRegistryWithDisciplines`:
  синхронизирует раздел/код/номер по официальному реестру и подгружает
  дисциплины из seed-чанков `convex/seedData/disc-01.json` … `disc-10.json`.
  Безопасно перезапускать — обновляет существующие записи по `slug`, новые
  добавляет.
- `convex/seedData/disc-01.json` … `disc-10.json` — консолидированный список
  дисциплин (4015+ записей, 194 вида спорта с дисциплинами). Весовые
  категории укрупнены в одну обобщённую запись на вид спорта + стиль
  (например, «Весовая категория» вместо десятков отдельных записей по 48 кг,
  52 кг и т.д.) — так решил пользователь, когда мы обсуждали масштаб сырых
  данных (6147 → 4015 записей).
- `convex/lib/authz.ts` — **заглушка** `requireUserId` только для того, чтобы
  этот фрагмент компилировался отдельно от основного проекта. В Macaly он
  заменяется на настоящую проверку сессии через `@convex-dev/auth`.
- `src/data/sports-registry.json` — 206 видов спорта из реестра ВРВС:
  название, slug, раздел (`recognized` / `all_russian` / `national` /
  `applied`), полный код реестра, номер по порядку в разделе и число
  дисциплин. Номера в разделе «признанные» (`recognized`) исправлены —
  раньше шли в алфавитном порядке, теперь в официальном порядке реестра.

## Как слить обратно в основной проект (Macaly)

1. Скопировать `convex/schema.ts` (объединить таблицу `sports` со
   схемой основного проекта — остальные таблицы `venues`, `events`,
   `banners`, `authTables` там уже есть).
2. Скопировать `convex/sports.ts`, `convex/migrations.ts`,
   `convex/seedData/*.json`, `src/data/sports-registry.json`.
3. Удалить `convex/lib/authz.ts` — в основном проекте уже есть настоящий.
4. Задеплоить: `npx convex deploy -y`.
5. Прогнать миграцию: `npx convex run migrations:syncRegistryWithDisciplines --prod -y`.
